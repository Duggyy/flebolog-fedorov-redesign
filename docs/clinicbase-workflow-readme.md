# Редактируемая схема ClinicBase

Файл схемы:

`docs/clinicbase-workflow.drawio`

Как открыть и редактировать:

1. Откройте https://app.diagrams.net/
2. Выберите `Device`.
3. Нажмите `File` → `Open From` → `Device`.
4. Выберите файл `clinicbase-workflow.drawio`.
5. Редактируйте блоки, подписи и стрелки.
6. Сохраните обратно через `File` → `Save`.

В файле две страницы:

- `Workflow` — путь пользователя по сайту и базе приемов.
- `Data/API` — связь фронтенда, PHP API и таблиц MySQL.

Как использовать как задание для Codex:

1. Измените схему визуально.
2. Сохраните `.drawio`.
3. Пришлите этот файл мне и напишите, что нужно реализовать по схеме.

Важно: если схема меняет структуру базы данных, SQL нужно обновлять отдельной миграцией, а не повторным импортом полного `clinicbase.mysql.sql`.
